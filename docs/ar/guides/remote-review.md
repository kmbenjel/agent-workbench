# المراجعة من حاسوب بعيد

قد تراجع من هاتفك، أو يكون حاسوب الوكيل نائمًا، أو تكون الصفحات ثقيلة. فتُبنى الصفحة عندك ثم **تُخدَّم من
حاسوب بعيد** يستمع على واجهته الداخلية فقط (`127.0.0.1`)، وتصل إليه بنفق `ssh -N -L` فيبقى العنوان المحلي كما هو.
لا منفذ مفتوحًا ولا عنوانًا ثابتًا ولا حسابًا.

## الإعداد

في `workbench.toml`:

```toml
[remote]
provider = "gcloud"        # أو ssh أو command
instance = "review-box"
zone = "europe-west1-b"
```

- `provider = "ssh"` مع `host = "user@host"` لحاسوب يعمل دائمًا.
- `provider = "command"` مع `status_cmd` و`address_cmd` و`start_cmd` و`stop_cmd` لأي مزوّد آخر؛ يطبع `status_cmd`
  الكلمة `RUNNING` حين يعمل الجهاز.

على الجهاز البعيد: بايثون 3 و`rsync` وإتاحة ssh بالمفتاح. الحزمة نفسها تُدفع إليه.

## الاستعمال

```bash
awb remote up
```

يشغّل الجهاز إن كان مطفأً، ويدفع الحزمة والصفحات، ويبدأ الخادم برمز سرّي مولَّد، ويفتح وحدة النفق ووحدة المزامنة،
ثم يطبع العنوان:

```text
http://127.0.0.1:8765/index.html?k=<الرمز>
```

كل 20 ثانية تسحب المزامنة الملاحظات المحفوظة هناك إلى ملفك المحلي (فيعمل `awb watch` كما هو) وتدفع ما تغيّر.
وإذا لم تبقَ بطاقة مفتوحة أخذت سحبة أخيرة وأطفأت الجهاز والنفق.

النفق يعمل على جهاز الوكيل، فهذا العنوان يُفتح عليه. أما الهاتف أو الحاسوب الآخر فيصل إلى الصفحة بعميل ssh خاص به
(على أندرويد مثلًا: Termux) يفتح النفق نفسه، `ssh -N -L 8765:127.0.0.1:8765 user@vm`، ثم يفتح العنوان الذي يطبعه
`awb remote url`.

```bash
awb remote down     # الإطفاء يدويًا
awb remote url      # طباعة العنوان
```

!!! tip "تهيئة مبكرة"
    إن كانت المهمة ستنتهي بصفحة مراجعة، فشغّل الجهاز البعيد في أولها لا حين يحين موعد الصفحة، وابنِ الصفحات
    الثقيلة عليه لا على حاسوبك.

## الأمان

الرمز يُنقل عبر ssh إلى ملف بصلاحيات 0600 ولا يظهر في سطر أمر. والخادم يرفض أي طلب ترويسة `Host` فيه ليست محلية،
وأي طلب POST ليس JSON، وأي `Origin` غريب، ولا يسمح لموقع آخر بأن يعرض الصفحة داخل إطار.

!!! tip "بلا حاسوب يعمل"
    إن كانت المادة مما يصح نشره وأردت رابطًا عاديًا يُفتح من الهاتف، فانظر [المراجعة من موقع ثابت](static-review.md).
