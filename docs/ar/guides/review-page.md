# صفحة مراجعة لمهمتك

## البطاقات

لكل قرار بشري بطاقة واحدة. اكتبها في ملف JSONL، سطر لكل بطاقة:

```json
{"id": "book-0042", "section": "names", "title": "اقتراح اسم", "subtitle": "المجلد الثاني", "why": "الغلاف يخالف صفحة العنوان", "body": "الحالي: ...\n\nالمقترح: ...", "images": ["scans/0042.png"]}
```

- `id` معرّف **ثابت** تختاره أنت (يفضّل أن يشتق من الكتاب نفسه). لا يتغيّر عند إعادة بناء الصفحة، ولا تُرقَّم
  البطاقات المخفية من جديد، فلا تتحوّل ملاحظتك إلى بطاقة أخرى.
- `why` سبب شكّ الوكيل، وفيه رأيه إن كان له رأي. لا تعرض على صاحبك إلا ما يشكّ فيه فعلًا.
- `images` مسارات صور أو روابط.

## البناء والتقديم

```bash
awb page build names --cards cards.jsonl --title "أسماء للتأكيد"
awb serve
```

واضبط العربية في `workbench.toml`:

```toml
[page]
lang = "ar"
dir = "rtl"
title = "مراجعة"

[page.labels]
approve = "موافق"
reject = "ارفض"
comment = "تعليقك (اختياري)"
```

## أخبار وأسئلة

```bash
awb news post "صحّحت 212 خطأً وبقيت 7 أسطر لعينك" --kind question --title "سبعة أسطر"
```

السؤال تظهر تحته خانة جواب، ويصل جوابك إلى الوكيل ملاحظةً من نوع `REPLY`.

## الاستقبال والإغلاق

```bash
awb watch
```

يطبع سطرًا لكل ملاحظة استقرّت (توقفت عن الكتابة 45 ثانية، ويمكن تغييرها بـ `--settle`). يحفظ موضع القراءة، فلا
يضيع شيء إذا أُعيد تشغيله. وللاستعلام اليدوي: `awb remarks` (المفتوحة فقط، أو `--all`).

بعد أن يعمل الوكيل بالملاحظة:

```bash
awb close names book-0042 'صحّحت الاسم: «اقرأه كما في صفحة العنوان»'
```

يجب أن تقتبس الملاحظة كلام المراجع بين «» وأن يكون مسجّلًا فعلًا لتلك البطاقة، أو تقول `my judgment` إن كان
القرار للوكيل، أو تبدأ بـ `REOPEN` لإعادة فتح بطاقة.

!!! warning "تنبيه"
    علامة «موافق» بلا تعليق تعني الموافقة على الاقتراح كما هو معروض، فينفّذه الوكيل. وعلامة «ارفض» بلا تعليق سؤال:
    يعيد الوكيل النظر أو يسأل في الأخبار.

## الصيغة

الملفات في `.workbench/` بصيغة JSONL، وتفصيلها في `docs/protocol.md`، فيستطيع أي إطار وكلاء الكتابة فيها
والقراءة منها.
