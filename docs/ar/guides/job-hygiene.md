# صحّة المهمة

الأعمال الطويلة تأكل الذاكرة وتزاحم الشبكة وتموت أحيانًا في منتصف الطريق. تقدّم العدّة أدوات صغيرة لذلك كلها
في ملف `workbench.toml` نفسه.

## حارس الذاكرة

```bash
awb governor
```

شغّله خدمةً في الخلفية قبل الأعمال الثقيلة. يكتب عدد العمّال المسموح به في `.workbench/workers`، ومهمتك تقرؤه قبل
أن تبدأ كل وحدة عمل. وحين تضيق الذاكرة يتدرّج بأخفّ إجراء يكفي:

1. **يُوقف مؤقتًا** (SIGSTOP) أكبر عملية ثقيلة؛ تحتفظ بذاكرتها لكنها لا تكبر.
2. **يقتل** أكبر عملية إن صارت الذاكرة حرجة.
3. **يستأنف** الموقوفة واحدةً واحدة حين تهدأ الذاكرة.

لا يمسّ العمليات المحمية (سطح المكتب والمحررات والحارس نفسه). وضبطه في `[governor]`: `warn_gb` و`kill_gb` و
`pause_mb` و`job_patterns` و`protect_units`. وإغلاق المتصفحات الخاملة اختياري: `close_idle_browsers = true`.

## تهدئة الشبكة

لا تجعل أحدًا في البيت يتأخر في لعبة أو مكالمة بسبب تنزيل كبير:

```bash
awb calm wait 10 && awb queue run queue.tsv
awb netguard -- aria2c -i links.txt
```

الأول ينتظر عشر دقائق من الهدوء، والثاني يوقف الأمر ما دامت الشبكة مشغولة ثم يستأنفه. الإشارة هي زمن الاستجابة إلى
الراوتر وإلى الإنترنت.

## إعادة التشغيل

```bash
awb run --log job.log -- python my_job.py
```

إذا أُوقفت المهمة (بالحارس أو بإعادة تشغيل)، انتظر الأمر حتى تعود الذاكرة ثم أعادها لتتابع من حيث وصلت، وتوقف بعد
عدد من المحاولات لا تقدّم فيها.

## البطارية

```bash
awb power
```

يوقف المهام مؤقتًا عند بطارية منخفضة، ويستأنفها عند عودة الشاحن.
