# الاستعمال مع Claude Code

بعد تثبيت الإضافة ([التثبيت](../install.md)) يتعلّم الوكيل حلقة المراجعة من مهارة `review-loop`:

- يبني البطاقات ويقدّم الصفحة.
- يشغّل `awb watch` **مراقِبًا دائمًا** (أداة Monitor)، فيصله كل جواب إشعارًا من سطر واحد.
- يعمل بكل ملاحظة ثم يغلقها باقتباس كلامك.
- يخبرك في **الصفحة** لا في الطرفية، لأنك لا تقرأ الطرفية باستمرار.

الأوامر: `/agent-workbench:review` لبناء صفحة وبدء المراقبة، و`:news` لنشر خبر أو سؤال، و`:watch`، و`:status`.

## أدوات MCP

| الأداة | وظيفتها |
|---|---|
| `make_review_page` | تنشئ صفحة من بطاقات (معرّفات ثابتة) وتبنيها |
| `post_news` | تنشر خبرًا أو سؤالًا في لوحة الأخبار |
| `read_remarks` | تقرأ الملاحظات غير المُغلقة |
| `close_card` | تغلق بطاقة بملاحظة تقتبس المراجع |

خادم MCP لا يعتمد على أي حزمة، ويعمل على المجلد الذي فيه `workbench.toml`.

## أي إطار آخر

لا تحتاج الإضافة: كل أمر `awb` يعطي مخرجًا آليًا (`--json`) حيث يلزم، والملفات JSONL مفتوحة. مثال حلقة بسيطة:

```bash
awb watch --json | while read -r line; do echo "$line" | my-agent --handle-remark; done
```
