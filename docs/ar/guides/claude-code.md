# الاستعمال مع Claude Code

ثبّت الإضافة بأمرين داخل Claude Code:

```text
/plugin marketplace add kmbenjel/agent-workbench
/plugin install agent-workbench@agent-workbench
```

بعدها يتعلّم الوكيل حلقة المراجعة من مهارة `review-loop`:

- يبني البطاقات ويقدّم الصفحة.
- يصله كل جواب **إشعارًا من سطر واحد**: حين تُستدعى المهارة تشغّل الإضافة مراقِبها `remarks`، وهو الأمر `awb watch`
  في مجلد الجلسة، فلا يحتاج الوكيل إلى أن يتذكّر تشغيله.
- يعمل بكل ملاحظة ثم يغلقها باقتباس كلامك.
- يخبرك في **الصفحة** لا في الطرفية، لأنك لا تقرأ الطرفية باستمرار.

الأوامر: `/agent-workbench:review` لبناء صفحة وبدء المراقبة، و`:news` لنشر خبر أو سؤال، و`:watch`، و`:status`.

## ما تحمله الإضافة

| الجزء | وظيفته |
|---|---|
| المهارات | `review-loop` و`remote-review` و`job-hygiene` |
| الأمر `awb` | يأتي مع الإضافة (`bin/awb`) ويكون في `PATH` الوكيل ما دامت مفعّلة، فلا تثبيت آخر |
| المراقِب `remarks` | يبدأ `awb watch` أول مرة تُستدعى فيها مهارة `review-loop` |
| خادم MCP | الأدوات الأربع أدناه |

!!! note "مراقِب واحد لكل مساحة عمل"
    يبثّ ملاحظاتِ المساحة مراقِبٌ واحد في كل وقت. إن شُغّل `awb watch` ثانيًا قال أيّ عملية تمسك بالبثّ ثم خرج، فلا
    تصل الملاحظة مرتين. والمراقِبات تعمل في الجلسات التفاعلية؛ أما في التشغيل الصامت (`claude -p`) فيستطلع الوكيل
    `awb remarks`.

## أدوات MCP

| الأداة | وظيفتها |
|---|---|
| `make_review_page` | تنشئ صفحة من بطاقات (معرّفات ثابتة) وتبنيها |
| `post_news` | تنشر خبرًا أو سؤالًا في لوحة الأخبار |
| `read_remarks` | تقرأ الملاحظات غير المُغلقة |
| `close_card` | تغلق بطاقة بملاحظة تقتبس المراجع |

خادم MCP لا يعتمد على أي حزمة، ويعمل على المجلد الذي فيه `workbench.toml`.

## أي إطار آخر

لا تحتاج الإضافة: كل أمر `awb` يعطي مخرجًا آليًا (`--json`) حيث يلزم، والملفات JSONL مفتوحة. مثال حلقة بسيطة:

```bash
awb watch --json | while read -r line; do echo "$line" | my-agent --handle-remark; done
```
